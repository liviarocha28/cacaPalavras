# Palavra do Dia

Um jogo casual diário de adivinhação de palavras em português, feito com HTML, CSS e JavaScript sem dependências. O tema inicial é “Memes absurdos” e a interface principal implementa o protótipo UX “Jogo sem atrito”.

## Como jogar

Abra `index.html` no navegador. A cada dia há uma palavra secreta temática de cinco letras e seis tentativas. As letras coloridas mostram quais estão no lugar certo ou aparecem em outra posição. Palpites repetidos não são aceitos. O progresso e as estatísticas ficam salvos neste navegador.

Use o teclado físico ou o teclado na tela. Tentativas precisam ter cinco letras e estar no vocabulário local do jogo; palavras incomuns, acentuadas ou variantes regionais podem não estar incluídas. A palavra do dia muda com a data local do dispositivo. Ao concluir, copie ou compartilhe o padrão de pistas sem revelar a solução.
